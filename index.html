Fém darabolás tervező

Szálanyag-optimalizálás gérvágással – offline is működik.

Beállítások

Szálanyag

Üres darabszám = korlátlan. Maradékdarabot is felvehetsz külön sorban.

Darabok

Hossz = a hosszabbik oldalon mérve (csúcstól csúcsig). Szög: 0 = egyenes vágás, 45 = gérvágás. Profil = a szelvény mérete a vágás síkjában (pl. 40×20-as zártszelvény 40-es oldalán gérelve: 40). Azonos szögű és profilú végeket a program egy közös vágással egymásba illeszt.
